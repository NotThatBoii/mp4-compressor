Compress and convert videos on Windows 10/11 (64-bit Intel or AMD laptops).
Convert to MP4, MOV, MKV, WebM, AVI, WMV, FLV, MPG, TS, M4V or 3GP.

Python, Qt and FFmpeg are included. No additional downloads or software setup are required to use the installed app.

Setup installs for your Windows account and adds a Start menu shortcut. You can remove Compressly later through Windows Settings > Apps. Your original videos and output files are not deleted when you uninstall.

Close Compressly before installing an update. This installer will not forcibly terminate an active compression job.

This release is unsigned. Windows may show an Unknown Publisher or SmartScreen notice. Only install files downloaded from the project's GitHub Releases page.

Known limits: one video at a time, no HDR conversion, no pause. CPU AV1 requires an FFmpeg build containing SVT-AV1; the included essentials build supports CPU H.264 and H.265. Hardware encoders depend on your laptop and drivers.
